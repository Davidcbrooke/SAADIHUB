Connect the staffing sheet and Breathe

The page reads the rota sheet and Breathe through a small Google script that keeps the Breathe key private. It only passes names, roles and time-off dates to the Hub: never pay, bank, address or the reason someone is off.

  1. Open script.google.com signed in as the account that can open the staffing sheet. Name the project SAADI Hub Staffing.
  2. Delete what's there and paste in the connector code:
  3. Cog (Project settings) > Script properties > add three:
    BREATHE_API_KEY = your Breathe key
    SHEET_ID = …
    TOKEN = …
  4. Deploy > New deployment > type Web app, Execute as Me, Who has access Anyone > Deploy, allow access, and copy the Web app URL.
